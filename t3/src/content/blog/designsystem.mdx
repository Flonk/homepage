## FLB

Any border on an object should be an *FLB* (fake luminosity border).

<Specimen
  name="On a flat colour"
  note="If the element is a flat color, its border can be a real CSS border; same color but 20% lighter."
  code={`background: var(--nord0);
border: 1px solid <that colour, lifted>;`}
>
  <FlbSolids />
</Specimen>

<Specimen
  name="On a ramp"
  note="If the content is a gradient or some other sort of non-solid colour, the border must be emulated to show a fake 1px ring of the same colour, 20% lighter, around the element."
  code={`background:
  <the ramp> padding-box,        /* stops at the inner edge */
  <the ramp, lifted> border-box; /* only the ring is left for it */
box-sizing: border-box;
border: 1px solid transparent;   /* reserves the ring, paints nothing */`}
  ground="dark"
>
  <FlbBar />
</Specimen>
