## FLB

Any border on an object should be an *FLB* (fake luminosity border). If the element is a flat color, its border can be a real CSS border; same color but 20% lighter.

<FlbSolids />

If the content is a gradient or some other sort of non-solid colour, the border
must be emulated to show a fake 1px ring of the same colour, 20% lighter,
around the element.
